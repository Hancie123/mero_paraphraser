# models/

Optional, for development: put a GGUF model here named `model.gguf` and the engine uses it instead of the installed one.

The installed model normally lives in `%LOCALAPPDATA%\com.merovision.paraphraser\ai\models\`. The app downloads the pinned model there automatically, and release installers copy it from the `ai\` folder that ships next to the installer.

Files in this folder are not committed.
